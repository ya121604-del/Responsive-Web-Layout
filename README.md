# Project 2 – Responsive Web Layout

## Overview
This project was developed as part of the Frontend Development Internship at DecodeLabs. It focuses on creating a responsive webpage that works across different screen sizes.

## Technologies Used
- HTML5
- CSS3
- CSS Media Queries

## Features
- Responsive navigation
- Mobile-friendly layout
- Proper spacing and alignment
- Responsive design for different screen sizes
- Clean and readable layout

## Objective
The objective of this project is to practice responsive web design and CSS layout techniques using media queries.
